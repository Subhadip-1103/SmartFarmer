# SmartFarmer

SmartFarmer contains a Django backend and a React frontend.

## Project folders

- `farmconnect-backend/` — Django API, models, and backend requirements
- `farmconnect-frontend/` — React web application

## Run locally

Start the backend from `farmconnect-backend/` with `python manage.py runserver`.
Start the frontend from `farmconnect-frontend/` with `npm install` followed by `npm start`.
